# Task3_ML-AL_Regression
🏡 House Price Prediction using Machine Learning
 I have completed my 3rd task of AI & ML INTERNSHIP of Elevate Lab.In this project worked on a real-world dataset of Bengaluru housing prices to build a predictive model using machine learning 🐍.

🛠 Tools & Technologies:
1)Python
2)Pandas, NumPy
3)Matplotlib
4)Scikit-learn

📊 Project Highlights:

Data Cleaning and Preprocessing (handled missing values, removed outliers, engineered features like BHK and price per sqft)

Exploratory Data Analysis (EDA) with Pandas and Matplotlib

Applied Simple and Multiple Linear Regression models

Achieved improved prediction accuracy by outlier removal and location-based feature transformation
